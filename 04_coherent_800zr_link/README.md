# 04 — Coherent 800ZR Link

## Objective

Develop an OIF 800ZR-aligned coherent optical link simulation for
single-span amplified data-center interconnect applications.

## Planned Scope

- Coherent transmitter and receiver architecture
- IQ modulation and coherent detection
- Fiber attenuation and chromatic dispersion
- EDFA gain, ASE noise, and OSNR
- DSP and constellation recovery
- BER versus OSNR
- 80–120 km link-level performance analysis
