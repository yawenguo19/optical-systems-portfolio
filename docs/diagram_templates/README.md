# Diagram Style Guide

This directory contains reusable draw.io templates and shape libraries
for the Optical Systems Portfolio.

## Typography

- Font: Arial
- Module text: 14 pt, bold
- Parameter text: 11 pt
- Diagram title: 18 pt, bold

## Colors

| Element | Fill | Border |
|---|---|---|
| Physical component | `#EAF3FF` | `#4A90E2` |
| Processing block | `#F2F2F2` | `#777777` |
| Optical channel | `#EAF7EE` | `#5B9A68` |
| Input/output | `#FFF4E5` | `#D99A3E` |
| Decision | `#F5EEFF` | `#8757B5` |

## Connectors

- Color: `#666666`
- Width: 1.5 px
- End arrow: Classic
- Use left-to-right signal flow whenever possible

## Export

- Primary format: SVG
- Background: White
- Embed fonts
- Keep the editable `.drawio` source file
