# Optical Communication Terminology

| Abbreviation | Full name | Description |
|---|---|---|
| ASE | Amplified Spontaneous Emission | Optical noise generated and amplified by an optical amplifier |
| BER | Bit Error Rate | Fraction of received bits detected incorrectly |
| CD | Chromatic Dispersion | Pulse spreading caused by wavelength-dependent propagation velocity |
| DSP | Digital Signal Processing | Digital algorithms used to recover and process received signals |
| EDFA | Erbium-Doped Fiber Amplifier | Optical amplifier commonly used in the C-band |
| EVM | Error Vector Magnitude | Difference between received and ideal constellation symbols |
| FEC | Forward Error Correction | Redundant coding used to correct transmission errors |
| GMI | Generalized Mutual Information | Achievable-rate metric commonly used for soft-decision receivers |
| IM-DD | Intensity Modulation–Direct Detection | Optical system using intensity modulation and photodetection |
| LO | Local Oscillator | Receiver laser used for coherent optical detection |
| OSNR | Optical Signal-to-Noise Ratio | Optical signal power relative to noise in a specified reference bandwidth |
| RRC | Root-Raised-Cosine | Pulse-shaping filter commonly used in communication systems |
