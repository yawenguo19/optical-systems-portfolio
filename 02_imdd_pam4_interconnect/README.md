# 02 — IM-DD PAM4 Interconnect

## Objective

Model and evaluate a short-reach intensity-modulation and
direct-detection optical interconnect using PAM4 signaling.

## Planned Scope

- PAM4 waveform generation
- Transmitter and receiver bandwidth limitations
- Noise and intersymbol interference
- Eye-diagram analysis
- BER and receiver sensitivity
- Equalization and link optimization
